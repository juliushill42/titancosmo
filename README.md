## 🎨 System Overview

`Cosmotologist` is an agile, ultra-lightweight frontend workbench that provides developers with a local control canvas to instantly generate, preview, and categorize atomic-level user interfaces. 

By mapping localized design style variables and target application frameworks directly against a dynamic system instruction payload matrix, the studio enables deterministic, client-side UI compilation without complex local dependency toolchains or build-step overhead.

### Integrated Design Engine Matrix

* **Framework Substrates:** Native selectors for React + Hooks, Vanilla HTML/CSS/JS, React + Tailwind, Svelte, HTMX + Go/Rust, and SolidJS (Signals).
* **Design Token Styles:** High-fidelity token themes including Clean Modern, Dark Luxury, Editorial, Minimal, Corporate, Playful, Glassmorphism, and Brutalist structures.
* **Atomic Hierarchy Mapping:** Generates components aligned strictly with localized design principles:
  * **Atom:** Focused single elements (Buttons, Inputs, Badges).
  * **Molecule:** Linked component groups (Search fields, Cards).
  * **Organism:** Structural sections (Navbars, Heroes, Footers).
  * **Template:** Skeletal layouts (Full-page compositions).
  * **Page:** Context-aware data targets (Live content containers).

---

## 🏗️ Technical Architecture & Implementation

The application maps state transformations natively within a single, highly performant client wrapper:

1. **Dynamic Prompt Compiler:** Combines token selections, primary aesthetic guidelines (hex value overrides), and structural constraints on-the-fly to insulate the inference generation against text drift or syntax leakage.
2. **Deterministic File Interrogator:** Computes appropriate source file extensions (`.jsx`, `.svelte`, `.html`) contextually based on active framework selections prior to token output stream compilation.
3. **Local Audit Pipeline:** Aggregates a run-time history array of prompt states and calculated code strings within an accessible localized memory loop, allowing instant history state reversion.
